P/01
MLOps · Model monitoring

MLOps Observatory

A health monitor for a credit-default model trained on 30,000 real credit card clients. It spots data drift and performance drops, retrains the model, and promotes v2 only if it beats v1.

0.81 → 0.43AUC under concept drift, caught
63automated tests
Live demo ↗ Code
  • Drift tests (PSI and Kolmogorov–Smirnov) implemented from scratch, shown as a per-feature, per-batch heatmap.
  • Retrain rule fires when max PSI > 0.2 or AUC drops by more than 0.05; a model registry compares v1 and v2 on the same holdout.
  • Live drift injector to break the model on purpose. It shows the “silent failure” where PSI stays green while AUC collapses.
  • FastAPI scoring service in a hardened Docker image, with GitHub Actions CI and one-click Render deploy.

P/02
NLP · LegalTech

AdharaAI

Upload a rental agreement, court notice or employment contract. AdharaAI flags risky clauses, explains every line in plain English and gives you an action checklist, built for Indian law.

30+risk rules for Indian law
80+plain-English rewrites
Code ↗
  • Reads PDFs, scanned images (Tesseract OCR) and plain text, then splits clauses with a 4-strategy segmenter for numbered, lettered, WHEREAS and paragraph styles.
  • Clause classifier fine-tuned from InLegalBERT and exported to ONNX, so production runs without PyTorch.
  • Privacy-first: no external APIs, and raw document text is deleted within 5 minutes.
  • Hardened FastAPI backend with rate limiting, magic-byte file validation and security headers. CI runs data-quality checks, tests and a Docker build.
