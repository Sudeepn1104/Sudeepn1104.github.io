Tiny MLOps Observatory

A dashboard that watches a loan-default model for data drift and performance drops, retrains it when a rule fires, and compares v1 with v2 before promoting.

The problem
Models fail quietly after deployment. Input checks alone miss some failures.
What I found
When the rule behind defaults changes but the inputs look normal, drift stays green while AUC falls from 0.70 to 0.43. So the retrain rule uses both drift and live performance.
What I built
PSI and KS drift tests from scratch, a retrain rule, a model registry, champion versus challenger promotion, a drift injector for live demos, and a model card that lists the limits.
